# VOLUME01 — Matveykin × wiluji · 07.11 · fābula HQ

Лендинг-«дело» для мероприятия. Статичный сайт без сборки и фреймворков: `index.html` + `assets/`.
Сделан в первую очередь под телефон. Весь сайт весит ~1.1 МБ, из них 430 КБ занимает тизер.

## Лор

**Дело № 07/11.** В ночь на 8 ноября 2004 года в клубе «VOLUME» шла закрывающая вечеринка.
В 03:59 музыка остановилась, зал оказался пуст, выход заперт изнутри, в центре зала нашли мёртвого сторожа.
На вертушке осталась пластинка с надписью VOLUME01. Объект опечатали.

В октябре 2026 на демонтаж заходит **бригада №6**. На сайте лежит её журнал:
лента, которая сама натягивается по кругу, кассета VOLUME01, телевизор с помехами без питания,
пропавший рабочий и светящийся жилет. Последняя запись сделана 26.10 в 03:59: «28 лиц на плёнке… не выключай звук».

**Протокол** выносит заключение: закрыть объект не получается, поэтому 07.11 в 18:00 его открывают снова
и набирают **бригаду №7**, то есть гостей. 28 лиц с плёнки — это лайнап, раздел так и называется: «Фигуранты».

Газеты на площадке хорошо продолжат этот лор: «вырезки» о фигурантах дела.

## Структура страницы

1. Вход: «ЗДЕСЬ ТЕМНО», кнопка «включить фонарь» или «войти со звуком». За сессию вход показывается один раз.
2. Hero: тизер-видео, 7.11, VOLUME01, кнопки билетов, переключатель звука.
3. 01 Справка: документ с закрашенными строками, тапом они открываются.
4. 02 Журнал работ: записи бригады и «улики». Фото тёмные, их подсвечивает луч фонаря: он идёт за пальцем или курсором, а если никто не трогает экран, гуляет сам.
5. 03 Протокол: штампы, каска.
6. 04 Фигуранты: лайнап со ссылками. При скролле имена «вспыхивают», как светоотражающая лента.
7. 05 Также на объекте: маркет.
8. 06 Допуск: пропуск со сменами, адресом, маршрутом и билетами, рядом афиша.
9. Липкая жёлтая кнопка «БИЛЕТЫ» снизу экрана.

## Как править

- Тексты, лайнап и ссылки лежат в `index.html`: каждый артист в списке `<ol class="roster">` — одна строка `<li>`.
- Дата обратного отсчёта задаётся в `assets/app.js` (`Date.UTC(2026, 10, 7, 15, 0, 0)` = 07.11 18:00 МСК).
- Цвета вынесены в переменные в начале `assets/style.css`.
- Шрифты (Unbounded, Oswald, IBM Plex Mono, Caveat) лежат локально и урезаны до кириллицы и латиницы.
  Если добавите текст с редкими символами, они отобразятся системным шрифтом.

## Запуск и деплой

Локально: `python3 -m http.server`, затем открыть http://localhost:8000.

Подойдёт любой статический хостинг: GitHub Pages (Settings → Pages → ветка, папка `/`), Netlify, Vercel, Яндекс Object Storage.
Файл `.nojekyll` уже лежит в репозитории.
